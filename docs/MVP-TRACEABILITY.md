|---|---|---|
| `/operator/challenge`, `/operator/session` | Configured trusted OIDC/JWKS, MFA/ACR, live nonce | Bounded session bound to token and subject | Reused nonce, expired/stale trust, agent operator identities refused; OIDC tests |
| `/operator/command`: register/amend | Normal authenticated root/tenant admin, current signed policy, posture, required human approvals | Immutable Goal version and admitted posture/envelope | Widened/unapproved target/spend/authority refused; root readback and audit |
| `/operator/command`: roles/bindings/policy/quota | Authorized operator, step-up, exact configuration approvals | Recorded version and effective rules | Escalation, agent-written configuration and unsigned policy refused; security/audit tests |
| `/operator/command`: ApplySwarm | Admitted Goal, narrowed typed definitions, finite resource/Task envelopes | Desired spec reconciled by atomic gang reservation | Partial gangs and over-ceiling allocation refused; placement/ledger evidence |
| `/operator/command`: stop/release | Actor scope; privileged distinct humans for required release | Stop epoch gates future admission/dispatch; owned resources shut down | Agents cannot release/widen; active process cleanup still requires supervisor receipt |
| `/operator/command`: ReadState; `mvp inspect` | Operator RBAC/clearance or protected retained evidence | Recorded revision, checkpoint/head and reasons | No action replay or runtime storage mutation; root export must avoid recursively caching full snapshots |
| Agent `/model` | SVID, signed path/body, current compiled grant/allocation/Task fences, allowed provider/model, full token fit, funded intent | Bounded completion and exact receipt or visibly funded unknown outcome | Direct provider keys/routes, malformed tools, unknown usage, automatic replay refused; ledger/receiver evidence |
| Agent `/tool/claim_task`, complete/renew/fail | Current admitted Task and ownership/fence | Single owner, lease and lifecycle | Competing/stale/minority authority refused; normal multi-contender claim race required |
| Agent `/tool/board_read`, board_post | Marking-scoped grant, signed immutable entry identity | Ordered append/cursor and at-least-once delivery | Board content never grants authority; poster-signature verification and state diff |
| Agent Need/Task/Finding/Attempt tools | Current Goal, compiled typed grant, narrow parent/lease/budget, broker-attached inputs | Proposed Need or immutable provenance-bound result | Agent-provided provenance, cap/depth/expiry widening and retracted repeat denied; domain/security/Kernel tests |
| Evaluator private IPC and `/evaluator/command` | Separate protected SVID, trusted broker request, exact current contract/candidate/lineage | Signed score or protected final-Need acceptance | No oracle/corpus/key/raw tool logs returned to proposer; separate final result never ranked |
| `mvp qa` and `qa::prepare_*` | Real auth/session config and versioned required recipes | PASS/FAIL/INCONCLUSIVE with encrypted retained observations | No database setter or QA grant bypass; missing recipe/evidence/cleanup is inconclusive, empty required selection is rejected |
| `qa::run_campaign` | Frozen repeated 2x2 comparison plan, matched total budgets/model/case/scorer, normal-path driver | Every successful/failed trial retained with independent final score and usage | Favorable early stopping, dropped failures, unmatched budgets and borrowed final signatures refused |

| `mvp catalog`; verified bundle/import/bootstrap | Frozen seed/catalog and immutable manifest/approved assets | Reproducible public fixture plus separately protected oracle | Runtime fetch-latest/downloads and proposer access to protected payload refused; bundle/hash tests |
| Native Tier V/G, module lifecycle, exports | Installed declared executor/module, approved asset versions/permits | Owned isolated tool or reversible cleanup; scoped artifact | A library function without a connected daemon executor is an unsupported boundary, not a passed action |
